UPDATE TO THE TASTEBUD PERSONAL BUILD

Branch: codex/tastebud-personal-core
https://github.com/tastebud23/movietasteapp/tree/codex/tastebud-personal-core

This update opens with For me: three worthwhile picks, your full favourite list and feedback that distinguishes interest, viewing and enjoyment. With someone keeps the two-person picker. Streaming and catalogue lookups are deferred.

RECOMMENDED — KEEP A SEPARATE TEST COPY
1. Choose Code > Download ZIP from the branch above.
2. Extract the full ZIP into a NEW folder. Keep the previous working folder.
3. Stop the running app with Control+C in its terminal.
4. Copy your existing .streamlit/secrets.toml locally into the new folder's .streamlit directory. Keep the original file and existing .venv environment.
5. Open the new app folder in VS Code and run it using the same Python environment as before.

No new dependencies, API key or model change are required. Keep the configuration that already works. An existing Watchmode key can stay; this build does not use it.

WINDOWS START COMMAND
If the .venv environment is one folder above app_ui.py, the previously used command is:
..\.venv\Scripts\python.exe -m streamlit run app_ui.py

If .venv is inside the current app folder:
.venv\Scripts\python.exe -m streamlit run app_ui.py

Run from the folder containing app_ui.py. A separately extracted folder may have a different relative path to your existing environment; point the command at that environment. Do not move or overwrite .venv just to match the example.

ALTERNATIVE — UPDATE THE EXISTING TEST FOLDER
For a copy already on codex/movie-taste-test, stop the app and keep a backup of that folder. Copy these files from the NEW download into the existing app folder:
  app_ui.py                 Replace
  feedback.py               Add
  solo_recommendations.py   Add
  storage.py                Replace
  pair_recommendations.py   Replace
  pair_ui.py                Replace

Keep all the other existing files, including accounts.py, solo_helpers.py, availability.py and the theme. Leave .streamlit/secrets.toml and .venv in place. The full branch ZIP is preferable if you are unsure which version you have.

If you already work with Git, use the codex/tastebud-personal-core branch in a separate checkout or after preserving your local work. This update should not overwrite uncommitted changes or local configuration.

SAVED PROFILES
No SQL migration is required for an existing movietaste_* installation. New feedback is added as events in movietaste_recommendation_events; existing movietaste_movie_feedback rows remain intact and provide the baseline.

Older unprefixed tables such as profiles and movie_feedback remain untouched and are not read by this build. This update does not migrate their data. Guest profiles are temporary; signed-in profiles persist through the configured account.

QUICK CHECK AFTER RESTARTING
- Confirm the landing page says Find your next good film. and opens For me.
- Try your usual full favourite list and judge the three picks.
- Try another round and check that earlier suggestions do not repeat.
- With a saved profile, save one film, mark another seen, and use Liked it only for a film you enjoyed.
- Add or change Tonight’s mood; the old result should clear.
- Open With someone and try two favourite lists.

A valid round uses one OpenAI request. Invalid output can trigger one additional validation retry. Each request has a 25-second timeout and SDK retries are off. Real speed and recommendation quality still need checking on your machine.

Keep secrets.toml local. Do not paste keys into chat or commit the file to GitHub.

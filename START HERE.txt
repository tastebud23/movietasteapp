START HERE — TASTEBUD PERSONAL BUILD

This build opens with three film picks for you. With someone keeps the two-person picker.

GET THE CURRENT COPY
1. Open https://github.com/tastebud23/movietasteapp/tree/codex/tastebud-personal-core
2. Choose Code > Download ZIP, then extract it into a separate folder.
3. In VS Code, choose File > Open Folder and select the folder containing app_ui.py.
4. Choose Terminal > New Terminal.

IF YOUR PREVIOUS COPY ALREADY WORKS
Keep its .venv environment and .streamlit/secrets.toml. No new packages or API key are needed.

Copy your existing secrets.toml locally into the new app folder's .streamlit folder. Keep the original. Do not paste the contents into chat or upload them to GitHub.

Run using your existing environment. If .venv sits one folder above the app, the previous Windows command was:
..\.venv\Scripts\python.exe -m streamlit run app_ui.py

If .venv sits inside the app folder instead:
.venv\Scripts\python.exe -m streamlit run app_ui.py

The path must point to the environment you already use. Downloading a ZIP does not create or move that environment. UPDATE TEST COPY.txt also explains how to update the existing folder in place.

FRESH WINDOWS INSTALL — run each line separately
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -m streamlit run app_ui.py

FRESH MAC/LINUX INSTALL — run each line separately
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m streamlit run app_ui.py

The first installation needs Python 3.12 and can take a few minutes. Leave the terminal running while using the app. Control+C stops it.

TRY IT AT HOME
- In For me, enter the same favourite films you used before. Your full list is welcome.
- Choose Find me a film. Check whether all three picks look worth watching and whether the reasons make sense.
- Choose Try three more. Earlier suggestions should not repeat during the session.
- Create a profile to save a pick. Already seen records viewing; Liked it records enjoyment and adds the film to your favourites. Saving for later is only interest.
- Try Not tonight. It skips that film for this session without recording a dislike.
- Add a short note in Tonight’s mood, then ask again.
- Open With someone and try both people’s favourite lists. The labelled example works without a key.

WHAT TO EXPECT
Personalised picks need your existing OpenAI configuration. There are no active streaming-service or Watchmode lookups in this build. Film details are generated and may need checking.

Guest profiles are temporary. Signed-in profiles persist through your configured Supabase account. Signing in does not import guest profiles. This update needs no SQL changes if you already use the movietaste_* schema; older unprefixed tables are still not read or migrated.

Automated checks use mocked AI and account responses. The useful next check is how the real picks feel with your own list, your existing credentials and someone you watch with.

If a command fails, share the error message with any credentials removed.

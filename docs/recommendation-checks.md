# Check the recommendations with real viewers

Use the same favourites when comparing versions. Record both viewers' answers separately. A persuasive explanation is not proof that a film is a good match.

| Case | First viewer | Second viewer | What to examine |
| --- | --- | --- | --- |
| Similar tastes | Arrival, Contact, The Martian | Interstellar, Moon, Ex Machina | A real shared connection without repeating favourites |
| Different tastes | Die Hard, Mad Max: Fury Road, John Wick | Amélie, Paddington 2, Little Women | Each viewer gets a specific reason; neither taste is ignored |
| Mixed favourites | Arrival, Knives Out, Shark Tale | Paddington, Get Out, Hunt for the Wilderpeople | Ask what tonight's mood/audience is instead of assuming family night |
| Family limits | Toy Story, Up | Paddington, Finding Nemo | Every chosen candidate has a confirmed US G/PG rating; inspect local guidance |
| Practical limits | Any two lists | Selected services and 90-minute maximum | Country, service, rental setting and runtime match the displayed metadata |
| Missing information | Any two lists | Restrictions with no Watchmode | No unverified recommendation claims to satisfy those restrictions |
| Several rounds | Any two lists | Keep pressing Try another pick | None of the earlier titles returns until a fresh session is explicitly started |

For each run, write down:

- Time until usable results appear.
- Each viewer's willingness to watch the main pick, from 1 to 5.
- Whether each explanation connects to a specific stated preference.
- Any incorrect title, remake, runtime, poster or availability.
- Whether a pair actually chooses a film, watches it, and enjoys it afterwards.
